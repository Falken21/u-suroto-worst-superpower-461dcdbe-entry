# Worst Superpower

This is a one-line entry for the Worst Superpower competition, inventing a superpower that sounds incredible and delivers nothing. The power is stopping time completely — a flagship ability — but only for exactly zero seconds at a time. It can be used as often as its owner likes, with no cooldown, yet that unlimited quantity never adds up to anything. Because every single use lasts no time at all, the power can never change anything.
